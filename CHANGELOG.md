## [4.0.0] - 2026-09-28

- Added a local history panel for the last 10 copied GitHub repository URLs.
- Added MIT licensing and open-source project documentation.
- Added repository URL validation and automated tests.
- Removed dynamic `innerHTML` usage from popup rendering.
- Added local development and continuous integration checks.
- Added extension icons, accessibility improvements, and a public-repository warning.
- Added popup behavior tests, release packaging, and GitHub issue templates.
- Separated translations and made service lists dynamic in generated prompts.
- Added a README preview and a reusable manual release checklist.
- Added localized interface and analysis prompts for five languages.
- Added links for GitIngest, GitDiagram, uithub, DeepWiki, and GitMCP.
