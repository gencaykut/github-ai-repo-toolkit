# Contributing

Thank you for considering a contribution.

## Development setup

1. Fork and clone the repository.
2. Install the development dependency with `npm install`.
3. Make a focused change.
4. Run `npm test`, `npm run check`, and `npm run format:check`.
5. Open a pull request that explains the problem and the proposed solution.

When changing repository URL parsing, add tests for both accepted and rejected
URLs. When adding a service or language, update the interface, generated prompt,
tests, and README together.

Please do not include credentials, private repository data, generated archives,
or unrelated formatting changes in a pull request.
